# UI-01 首批实现与验收

更新于 2026-09-17。根据 `img` 中五类参考图重新实现首页、市场情绪、热点、策略和账户布局，继续使用 XML/View、现有 ViewModel 和 Repository。

本次重做红色搜索头部、横向页签、三列指数卡、情绪仪表、机会卡、风险提示、策略 K 线与成交量、账户资产区、仓位圆环及持仓表格。首页改为参考布局，原驾驶舱通过“交易工具”入口保留。

真机截图：[首页](ui-review/home.png)、[情绪](ui-review/sentiment.png)、[热点](ui-review/hotspots.png)、[策略](ui-review/strategy.png)、[账户](ui-review/account.png)。这些是使用生产布局和渲染器的 **debug 离线设计样例**，不写入用户账户；[实际首页](ui-review/home-live.png)使用现有行情来源。由于设备屏幕比例不同，不能据此声称逐像素一致。

## 页面及入口

| 页面 | 实际内容 | 原有入口和返回规则 |
| --- | --- | --- |
| 首页 | 驾驶舱、风险、账户摘要、交易计划、图表、资金、复盘 | 原有功能保留；分析面板和滚动位置随切页保存 |
| 行情 | 三大指数报价、监控池涨跌及覆盖数量 | 搜索仅过滤三大指数；不把监控池统计当作全市场情绪 |
| 自选 | 当前监控证券、价格、涨跌和来源时间 | 搜索名称/代码；管理按钮进入设置；点证券进入详情 |
| 账户 | 四项摘要、导入来源时间、持仓/可卖/成本、金额隐私 | 同花顺核对及成交导入；点持仓进入详情 |
| 我的 | 监控状态、设置、同步导入、消息中心、启动/停止监控 | 使用已有 Activity 和服务入口 |

主导航复用 Fragment 实例，隐藏页面降到 CREATED，避免收集不可见页状态。MainActivity 保留唯一监控、同步及 AI 效果处理归属。重复点击主导航不叠加页面；详情加入原有返回栈并隐藏主导航。主页面系统返回先回首页，详情返回先回原页面。

## 字段契约及样例

| 字段 | 实现来源 | 单位及缺失语义 | 样例 |
| --- | --- | --- | --- |
| 指数点位/涨跌 | `MainUiState.snapshot.marketIndices` → `Quote` | 点；涨跌为百分数，保留符号；无有效报价显示 `--` | `3200.00 点 / +1.25%`，不是 `+125%` |
| 个股价格/涨跌 | `snapshot.quotes`；名称可回退持仓配置 | 元/股；缺价时涨跌也不作为有效报价显示 | `10.20 元 / -0.35%` |
| 行情时间/来源 | `Quote.time`、`snapshot.updatedAt/dataHealth` | 报价时间与快照更新时间分别展示；缓存明确仅供观察 | 缺时间显示“时间未提供” |
| 自选范围 | `MainUiState.monitoredCodes` | 规范化并去重；不是新的独立收藏表 | 移除/编辑沿用设置流程 |
| 监控池涨跌 | `DashboardSummaryMapper.market` | 上涨/下跌/平盘/未知及有效覆盖 | 10 只、8 只有效报价、2 只待行情 |
| 账户摘要 | `DashboardSummaryMapper.account` + `ImportedAccountPresenter` | 导入优先；元或百分数；本地累计盈亏明确为当前持仓浮盈 | 无现金不伪造完整资产/仓位；历史当日收益保持历史标题 |
| 导入信息 | `ImportedAccountMetricEntity.source/observedAt` | 同花顺导入或手工核对快照；上海时区完整时间 | 跨日快照不标为实时账户 |
| 持仓/可卖/成本 | `MainUiState.positions` | 股、股、元/股；可卖 null 与 0 区分 | “未提供”与“0”分别显示 |
| 金额隐私 | 账户页本地展示状态 | 同时隐藏摘要数值及持仓数量、可卖、成本；随系统重建保存 | 点击显示后恢复同一状态的数值 |

- 本次已完成首页视觉重排及三大指数真实分钟曲线；详情页指标仍归 UI-02。全市场情绪历史、板块历史曲线、真实账户收益率历史尚无数据源，生产页面显示待接入。AI 置信度与胜率等绩效指标分别展示，不互相替代。
