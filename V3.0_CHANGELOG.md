# V3.0.0 - Stability, Modularization & Backup

- Started real Gradle modularization with `:core:designsystem`; the app now consumes the theme from the library module.
- Added versioned JSON export/import for non-secret user state, signal history, trade records and AI analysis history.
- Backup intentionally excludes API keys, ChatGPT cookies and session tokens.
- Added import validation and transactional restore of persisted review/AI data.
- CI now runs for every pull request and still executes tests, lint and debug assembly.
- Kept Room migrations explicit; destructive migration fallback remains disabled.
