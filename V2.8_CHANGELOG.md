# V2.8.0 - R2 Scanner & Signal Lifecycle

- Added an R2 scanner across the configured watch/position universe.
- Added persisted signal lifecycle: IDLE -> WATCH -> READY -> TRIGGERED -> CONFIRMED / INVALIDATED.
- Added consecutive-cycle confirmation, notification cooldown and duplicate suppression.
- Foreground service notifications now react to lifecycle transitions rather than every refresh result.
- Added current lifecycle state and R2 scan ranking to the dashboard.
