# V2.4.0 - Architecture Foundation

## Core architecture
- Added `AStockGuardApp` + `AppContainer` so Activity and foreground Service share the same Settings/Market repository/database instances.
- Added `MainViewModel` + `MainUiState` + one-shot `MainEffect`; MainActivity no longer owns network/AI repository calls directly.
- Kept the project as one Gradle `app` module for this migration step; new code is package-layered first.

## Offline-first foundation
- Added Room 2.6.1 database `astock_guard.db`.
- Added `quote_cache`, `daily_bar_cache`, and `ai_analysis` tables.
- Tencent quote/history success writes through to Room.
- Tencent quote/history failure falls back to Room cache.
- Cached quote fallback sets `DataHealth.isStale=true`, converts non-HOLD local signals to `WATCH`, and suppresses foreground-service trading alerts.

## AI background analysis
- Added `HiddenChatGptSession`: a 1x1 attached WebView with off-screen preraster, sharing the existing WebView cookie session.
- Normal ChatGPT Web analysis remains on MainActivity; no visible page navigation is required.
- Login expiry, DOM failure, WebView main-frame error, send failure, or answer timeout triggers an explicit dialog to open `ChatGptWebActivity` for manual recovery.
- Existing visible ChatGPT Web page remains available as the recovery/diagnostic path.

## Structured AI strategy
- Prompt now requires `<ASTOCK_STRATEGY>...</ASTOCK_STRATEGY>` JSON.
- Added parser for market action/confidence/target position and per-stock BUY/HOLD/WATCH/SELL strategy.
- AI raw reply and parsed strategy are persisted to Room for future strategy history/backtest UI.

## Compatibility
- Existing `RiskEngine`, `R2Engine`, Tencent parsing and settings logic are intentionally not rewritten in this version.
- Kotlin stays at 1.9.24 / AGP 8.7.3; Room is pinned to 2.6.1 to avoid combining the architecture migration with a Kotlin 2.x toolchain migration.
